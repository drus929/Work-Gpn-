# Административные регионы

В слое 83 субъекта России с кодами `RU-*` по ISO 3166-2. Границы и русские названия взяты из Natural Earth Admin 1 — States, Provinces, версия 5.1.1, масштаб 1:50 млн, система координат WGS 84. Natural Earth распространяет картографические данные как общественное достояние (public domain). [Каталог Natural Earth](https://www.naturalearthdata.com/downloads/50m-cultural-vectors/50m-admin-1-states-provinces/) · [Условия использования](https://www.naturalearthdata.com/about/terms-of-use/)

Отбор по кодам `iso_3166_2` соответствует международно признанным границам. Геометрия автономных округов и областей сохранена в том виде, в котором её даёт этот обзорный набор. Общие границы используют одинаковые вершины. В Чукотском автономном округе геометрия разбита по 180-му меридиану. При крупном увеличении сохраняется исходная картографическая детализация 1:50 млн.

В версии 5.1.1 перепутаны коды `RU-MOW` и `RU-MOS`. Коду `RU-MOW` присвоены контур и название Москвы, `RU-MOS` — контур и название Московской области. В записи `RU-ALT` исправлено русское название Алтайского края. Подпись каждого региона привязана к точке внутри его геометрии. Источником служат координаты подписи Natural Earth. Для точек за пределами контура генератор подбирает внутреннюю точку крупнейшей части полигона.

## Обновление данных

Готовый слой хранится в [src/data/admin-regions.json](../src/data/admin-regions.json). Для воспроизведения скачайте [исходный ZIP Natural Earth](https://naturalearth.s3.amazonaws.com/50m_cultural/ne_50m_admin_1_states_provinces.zip) и запустите скрипт из корня проекта. Требуются Python 3 с привязками GDAL и зависимости приложения для проверки готового слоя. Генератор сверяет SHA-256 архива с закреплённым `61f79e6705e62a55d6bcf698394295a589af5e24a4b2684c6519dd35c1300bf6`, выбирает нужные атрибуты и округляет общие координаты до 0,001°. Внешние кольца ориентированы по часовой стрелке для сферического рендеринга в D3 Geo.

```sh
/usr/bin/python3 scripts/update-admin-regions.py /tmp/ne_50m_admin_1_states_provinces.zip
node --test tests/admin-regions.test.js
```
