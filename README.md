# Нефтеатлас

Одностраничный справочный атлас крупных НПЗ России. Vite, JavaScript, D3 Geo; географическая основа Natural Earth (world-atlas, public domain). Карта и шрифты поставляются локально, внешние API и ключи не требуются.

## Запуск

Node.js 22+ (проверено на 24), npm 11.

```sh
cd /workspace/Work-Gpn-
npm ci
npm run dev -- --port 5173
```

Проверки: `npm run build` и `node --test tests/*.test.js`. Production: `npm run preview -- --port 4173` после сборки. Проверка HTTP должна вернуть HTML с заголовком «Нефтеатлас»; в браузере проверьте появление маркеров и карточку выбранного НПЗ.

## GitHub Pages

Исходный код хранится в ветке `main`, готовый статический сайт — в `gh-pages`.
В Settings → Pages выберите **Deploy from a branch**, ветку **gh-pages** и каталог **/ (root)**.
После успешной публикации адрес сайта: `https://drus929.github.io/Work-Gpn-/`.

В `vite.config.js` задан базовый путь `/Work-Gpn-/`, необходимый для загрузки JS, CSS и шрифтов на GitHub Pages. Для обновления сайта выполните проверки и `npm run build`, затем опубликуйте содержимое `dist` в корне `gh-pages`, сохранив файл `.nojekyll`. Публикация из `main` автоматически не выполняется.

## Данные

`src/data.js`: 29 справочных записей с проектной мощностью от 3 млн т/год. Это начальный каталог, не подтверждённый актуальный реестр; мощности, владельцев и полноту списка необходимо сверять с отчётами компаний. Ссылки для сверки доступны в интерфейсе. Названия регионов в списке и карточках, выбранный регион подписан на карте. Железные дороги показаны схематично, без точных подъездных соединений.

Оперативный источник статусов не подключён. Все заводы изначально имеют статус «не проверен», который не означает работу завода. Красные маркеры и карточки поддержаны через `statusUpdates`: обязательны `status: 'outage'`, `cause: 'external'`, HTTPS-источник и дата `checkedAt` в формате YYYY-MM-DD. Перед внесением проверьте, что сообщение относится к текущей остановке, а не историческому происшествию или частичному ремонту. Карта не обновляет статусы автоматически. Секреты не нужны.
